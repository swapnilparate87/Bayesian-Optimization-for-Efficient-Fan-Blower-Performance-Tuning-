=====================================================================
SECTION 1 — PROJECT OVERVIEW
=====================================================================

This project builds an industrial AI system that optimizes fan blower
performance using:

1.  Vibration signals from sensors
2.  Feature engineering (statistical + FFT)
3.  Machine learning models
4.  Bayesian optimization to find optimal RPM
5.  MLOps pipeline (DVC + MLflow)
6.  Cloud-ready architecture (AWS compatible)
7.  Monitoring with Prometheus + Grafana

The system workflow:

Sensors → CSV vibration signals → Data ingestion → Feature engineering →
ML training → Model registry → Bayesian optimization → Optimal RPM

SECTION 4 — DATA INGESTION PIPELINE
=====================================================================

Goal: Convert Vibxpert CSV files into structured signals.

Steps:

1.  Read CSV file
2.  Detect where signal values start
3.  Extract ‘Value’ column
4.  Parse RPM, Axis, Reading from filename
5.  Save signal as numpy array

Example filename:

75A1.csv

Parsed values:

RPM = 75 Axis = A Reading = 1

Saved structure:

data/raw_signals/

75/ H_1.npy H_2.npy V_1.npy V_2.npy A_1.npy A_2.npy

=====================================================================
SECTION 5 — FEATURE ENGINEERING
=====================================================================

Each vibration signal produces features.

TIME DOMAIN FEATURES

mean std rms min max peak skewness kurtosis crest factor shape factor
impulse factor

FREQUENCY DOMAIN FEATURES (FFT)

dominant frequency spectral centroid spectral entropy band energy low
band energy mid band energy high spectral kurtosis spectral rolloff

Features per axis ≈ 19

Total features:

19 × 3 axis = 57 features + RPM + FlowRate

Final dataset columns ≈ 59

Rows:

88 RPM × 2 readings = 176 samples
